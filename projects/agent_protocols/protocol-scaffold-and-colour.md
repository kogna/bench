# Protocol Scaffold: Protocols Included in Current Research Report

## **Primary Protocols**
1. **Google Agent Payments Protocol (AP2)** - Cryptographically-verifiable user consent through "intent mandates"
2. **OpenAI/Stripe Agentic Commerce Protocol (ACP)** - AI agents as checkout facilitators for existing merchant infrastructure  
3. **Visa Agent Commerce Solutions** - Comprehensive AI-ready payment infrastructure with merchant acceptance framework
   - Visa Intelligent Commerce Platform (April 2025)
   - Visa Trusted Agent Protocol (October 2025)

## **Secondary Protocols & Standards**
4. **Model Context Protocol (MCP)** - Anthropic-led enterprise payment platforms and agent workflow providers
5. **Mastercard Agent Pay Merchant Acceptance Framework** - No‑code merchant acceptance with pre‑transaction agent registration
6. **x402 Protocol** - Industry-wide open standards (Orium leadership)
7. **Agentic Entity Objects (AEO/GEO)** - Orium-led agent identity standards
8. **Secure Remote Commerce (SRC) Extensions** - Visa/Mastercard collaborative effort for AI agents

# Missing Protocols/Standards That Should Be Included

Based on my web research, here are the most relevant missing pieces:

## **1. Agent2Agent Protocol (A2A)**
**Why critical**: **Foundational infrastructure** that AP2 builds upon. Google's A2A enables **direct agent-to-agent negotiation** rather than just agent-to-API interactions. **McKinsey specifically identifies A2A as core infrastructure** alongside AP2/ACP. Without A2A, you miss how agents actually discover and communicate with each other - the "missing discovery layer" problem.[1]

## **2. Coinbase x402 Protocol** 
**Why relevant**: **Cryptocurrency-native agent payments**. Visa explicitly claims "alignment with Coinbase x402" , and with **crypto adoption in commerce**, this represents the **blockchain/DeFi approach** to agent transactions. Could be significant for **cross-border agent commerce** and **programmable money** use cases.[2]

## **3. Agent Identity & Authentication Standards**
**Why essential**: **"Know Your Agent" (KYA)** emerging as new compliance requirement. **W3C Decentralized Identifiers (DIDs)** and **Verifiable Credentials** are becoming **foundational to agent trust**. Without identity standards, all payment protocols have **security and compliance gaps**.[1]

## **4. Cloudflare Web Bot Auth** 
**Why infrastructural**: **Underpins both Visa and Mastercard frameworks**. Not just authentication - it's the **technical foundation** that distinguishes legitimate agents from malicious bots. **Critical security layer** that enables merchant trust in agent transactions.[2]

## **5. ISO 20022 Extensions for AI Agents**
**Why regulatory**: **Global financial messaging standard** being extended for **agent-initiated transactions**. **Bank-level compliance** and **regulatory reporting** requirements. Essential for **enterprise agent commerce** and **cross-border regulatory compliance**.

## **6. Web3 Agentic Standards (ERC-7265, ERC-4626)**
**Why emerging**: **Ethereum-based agent transaction standards** for **DeFi integration**. Represents **decentralized approach** vs. traditional payment rails. **Growing institutional adoption** of blockchain-based agent automation.

## **Top Priority Additions:**
- **A2A Protocol**: Core infrastructure dependency
- **Coinbase x402**: Crypto-native alternative 
- **Agent Identity Standards**: Security/compliance foundation
- **Cloudflare Web Bot Auth**: Technical security layer

These would give you complete coverage of the **three paradigms**: traditional payment rails (Visa/MC), platform-mediated (Google/OpenAI), and crypto-native (Coinbase/Web3) approaches to agent commerce.

## Protocol Analysis from Industry Sources

### **Google's Agent Payments Protocol (AP2)**

**Industry Assessment** :[5][6][7]
- **Everest Group** calls it "one of the first serious attempts to standardize how AI agents can securely transact"[6]
- **60+ global partners** including Mastercard, American Express, PayPal, Coinbase, Salesforce[6]
- **PayPal endorsement**: "PayPal's global infrastructure, risk management systems, and two-sided network have been built over decades to provide the trust, compliance, and auditability that AP2 requires"[7]
- **Klarna adoption**: Joined AP2 saying it "reflects its evolution from payments provider to core infrastructure contributor"[3]

**Technical Reception**:
- **Loeb & Loeb law firm analysis**: Highlights AP2's focus on **"authorization, authenticity, and accountability"** through cryptographically signed mandates[8]
- **Payment-agnostic approach** supporting traditional cards, bank transfers, AND cryptocurrency[8][6]

### **OpenAI/Stripe Agentic Commerce Protocol (ACP)**

**Industry Momentum** :[9][10][11][12]
- **Production-ready implementation** with **Instant Checkout in ChatGPT** already live for Etsy sellers[10][11]
- **Shopify integration** coming: "more than a million Shopify merchants, such as Glossier, Vuori, Spanx, and SKIMS"[12]
- **Salesforce endorsement**: Announced support through Agentforce platform[13]
- **Merchant-centric design** praised for avoiding vendor lock-in[10]

### **Visa's Trusted Agent Protocol**

**Industry Response** :[14][15][16][17]
- **TSG Payments**: "establishes a foundational framework for agentic commerce"[16]
- **Digital Transactions**: Notes Visa's **interoperability focus** with OpenAI, Google, Stripe, and Coinbase[17]
- **Built on Cloudflare Web Bot Auth** with Microsoft, Shopify, Checkout.com, Worldpay, Adyen collaboration[16]
- **Live production system** with immediate GitHub availability[15]

## Key Takeaways from Industry Analysis

**Consensus Points**:
- **Transformational scale** comparable to e-commerce revolution but potentially faster[4][1]
- **Infrastructure war** with high stakes for platform control[2][18]
- **Trust and security** as primary technical challenges[17][16][6]
- **Retailer adaptation urgency** emphasized across consulting firms[4][1]

**Divergent Views**:
- **Interoperability vs. Competition**: Claims of collaboration vs. concerns about walled gardens[17][3][18]
- **Timeline assumptions**: Varying predictions on adoption speed and scale[4][1]
- **Technical approach**: Cryptographic proofs vs. merchant-centric vs. network-based solutions[10][16][6]

The industry appears to be in rapid experimentation phase, with significant investment and partnership announcements, but underlying tension about whether these protocols will truly interoperate or fragment the market.
